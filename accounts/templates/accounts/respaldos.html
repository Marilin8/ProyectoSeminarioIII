Cómo obtener el Client ID y el Client Secret (una sola vez)
  1. Entre a console.cloud.google.com con la cuenta de Google donde quiere guardar los respaldos y cree un proyecto.
  2. En APIs y servicios → Biblioteca, busque Google Drive API y actívela.
  3. En Pantalla de consentimiento de OAuth: tipo Externo, agregue el permiso .../auth/drive.file y pulse Publicar aplicación (si queda en «Prueba», Google cancela el acceso a los 7 días).
  4. En Credenciales → Crear credenciales → ID de cliente de OAuth: tipo Aplicación web. En «URI de redireccionamiento autorizados» pegue exactamente:
    {{ uri_redireccion }}
  5. Copie el ID de cliente y el Secreto en este formulario.
