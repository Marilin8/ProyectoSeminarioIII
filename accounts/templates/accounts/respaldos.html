Cómo obtener el Client ID y el Client Secret (una sola vez)
  1. Entre a console.cloud.google.com con la cuenta de Google donde quiere guardar los respaldos y cree un proyecto.
  2. En APIs y servicios → Biblioteca, busque Google Drive API y actívela.
  3. En Pantalla de consentimiento de OAuth: tipo Externo, agregue el permiso .../auth/drive.file y pulse Publicar aplicación (si queda en «Prueba», Google cancela el acceso a los 7 días).
  4. En Credenciales → Crear credenciales → ID de cliente de OAuth: tipo Aplicación web. En «URI de redireccionamiento autorizados» pegue exactamente:
    {{ uri_redireccion }}
  5. Copie el ID de cliente y el Secreto en este formulario.

Restaurar desde un archivo

Suba un respaldo (.zip o .zip.cif), por ejemplo uno bajado de Google Drive, y el sistema vuelve a cargar toda la información que contiene.

Abrir el formulario de restauración
Esto reemplaza TODA la información actual (pacientes, citas, pagos, usuarios…) por la del respaldo. Antes de tocar nada el sistema verifica el archivo y guarda un respaldo de seguridad del estado actual; si algo falla, deja todo como estaba. Hágalo fuera del horario de atención: todos los usuarios tendrán que iniciar sesión de nuevo.
{% csrf_token %}

Por la web se pueden subir archivos de hasta unos 100 MB. Si el respaldo pesa más (por las imágenes), use en el servidor python manage.py restaurar_respaldo ARCHIVO. {% if not cifrado_activo %}Si el archivo es .cif hace falta la RESPALDOS_CLAVE en el .env.{% endif %}

Los respaldos contienen datos personales de pacientes: descárguelos y guárdelos en un lugar seguro (otro equipo o disco externo). En el servidor se guardan en {{ carpeta }}; un respaldo que queda solo en el mismo equipo no protege contra la pérdida de ese equipo. Eliminar un respaldo aquí no lo borra de Google Drive. {% if cifrado_activo %} Guarde la clave RESPALDOS_CLAVE del archivo .env en un lugar seguro fuera de este equipo: sin ella, los respaldos cifrados no se pueden recuperar. {% endif %}
